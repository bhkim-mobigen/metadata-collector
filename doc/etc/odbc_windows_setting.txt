tibero odbc python에서 사용
- 아래 사이트에서 sqlalchemy-tibero clone : pip install sqlalchemy-tibero 가 안되서 직접 install 수행
  . https://github.com/cpyang/sqlalchemy-tibero/tree/master
- pycharm으로 열어 venv 환경 설정 해준다. 3.9 로 했음.
- (venv) python setup.py install 수행히준다.
- 아래 빌드 결과물을, 사용할 프로젝트의 venv/Lib/site-packages/ ( or lib경로 만들어 복사 후 src 경로로 지정) 하위 경로에 복사해준다.
  . sqlalchemy-tibero/build/lib/sqlalchemy_tibero
  . sqlalchemy-tibero/sqlalchemy_tibero.egg-info
- pyodbc 테스트 수행한다.
  . multiline_query.py --dbms=tibero --host=tibero6_seoul_dsn --user=seoul_stg --passwd=etl_staging --db=big_portal
